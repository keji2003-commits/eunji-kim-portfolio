# Eunji Kim — Portfolio

Interactive 3D portfolio of Eunji Kim.

**Live site:** https://eunji-kim-portfolio.vercel.app

## About

A 3D studio scene you can explore by clicking objects in the room:

- **Character** — About
- **Locker** — Work
- **Mirror** — Now
- **Hangtag on the door** — Contact

The character, locker, mirror and sneakers were made in Meshy and assembled in three.js.

## Run it

This is a single-file website. Open `index.html` in a browser, or visit the live site above.
three.js is loaded from a CDN, so an internet connection is needed for the 3D scene.
